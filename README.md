## 비중 재검토 개정판 (2026-11-02 v3)

- [비중 재검토 PPT v3](reports/ETF_1억원_장기투자_4시나리오_비중재검토_2026-11-02_v3.pptx): 균형형 선호를 반영해 258개 비중, 기간 분리, 네 매매 전략, 거래 주기·비용 및 환율 스트레스를 비교했다.
- [계산 결과·전체 비중 CSV·재현 코드](reports/allocation_review_2026-11-02_v3.zip)
- 조건부 검토 후보는 **SCHD 10% / QQQM 45% / IEF 25% / IAUM 20% + 분기 ±5%p 전체 조정(A)**. 앞 10년의 두 대체자료에서 원화 MDD 20%, 달러 환산 순자산 MDD 30% 제약을 통과한 A·D 후보 중 보수적인 CAGR를 최대화했다. 달러 한도와 탐색 범위는 연구 가정이다.
- 후반 10년 고정 적용 시 후보 A의 보유 CAGR 14.91%, MDD −18.20%. 기존 비중 A는 14.60%, −17.38%, 기존 비중 D는 14.52%, −16.36%. 수익 개선과 낙폭 확대를 함께 판단한다.
- 기간 분리는 사후 설계이며 독립적인 미래 검증이 아니다. 20%는 사용자 선호이고 실제 손실 상한이 아니다. 기존 계좌 전환 세금·개인 배당세·환전비용은 별도 검토가 필요하다. Pine·운용 정책을 변경한 것이 아닌 연구 제안이다.
- 기존 v2의 15/40/25/20 결과는 v3 후반부에 비교 자료로 유지했다.

## 이전 투자 검토 (2026-11-02 v2)

- [이전 PPT: 4개 시나리오·보유 기준 CAGR](reports/ETF_1억원_장기투자_4시나리오_CAGR_2026-11-02_v2.pptx)
- [기존 방식과 전체 조정 비교: 결과·거래기록·재현 코드](reports/selective_vs_whole_rebalance_2026-11-02.zip)
- 초기 1억원, 목표비중 **SCHD 15% / QQQM 40% / IEF 25% / IAUM 20%**. 장기 원화 연복리수익률을 우선하고 MDD를 함께 평가한다.
- 수익률은 **보유 기준 CAGR**로 비교한다. 운용 중 비용·발생 양도세는 반영하지만, 종료일 가상 전량 매도 세금은 주지표에서 제외한다.
- 시나리오: A 전체 종목 조정, B 매수 후 보유, C 코어90%+Squeeze10%, D 사용자 기존 방식인 **분기 말 ±5%p 이탈 종목만 조정**.
- D의 매도 잔액은 USD 현금으로 두고 매수는 현금 범위에서 실행한다. 현금도 비중 계산에 포함한다. 현금 이자는 0%, 납세자금 부족 시 비례매도는 비교 모델의 공통 가정이다.
- 기본 20년 자료에서 A의 보유 CAGR 12.76%·MDD −17.54%, D는 12.62%·−16.26%. 대체 ETF에 따라 순위가 바뀌므로 A가 D보다 항상 우월하다고 결론 내리지 않는다.
- 기존 3전략 PPT와 세금·거래기법 ZIP은 연구 이력이다. `annual_gain_harvesting_2026-11-01.zip`은 **검토 후 제외한 전략**이며 현행 운용안이 아니다.
- 성과는 상장 전 대체 ETF, 편도 비용0.10%, 근사 양도세 모델을 사용한 과거 추정이다. 개인 배당세·환전비용은 제외했고 독립 워크포워드 검증은 없다. 미래 수익을 보장하지 않는다.
