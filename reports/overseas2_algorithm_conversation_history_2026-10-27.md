## 2. AI — 계획안 재작성

두 문서와 PRD·README를 읽고, 기존 테스트 17개를 다시 실행해 모두 통과하는 것을 확인했다. 그 뒤 [구축 계획안](overseas2_algorithm_build_plan_2026-10-27.md)을 새로 만들었다.

- **결론:** 알고리즘의 뼈대(분기 점검 → ±5%p 이탈 확인 → 확정 주봉 추세로 해석 보조)는 유지한다. 진행 순서는 **현금 정책 확정 → TradingView 실행 확인 → 원본 지표와 신호 대조 → 과거 데이터로 정책 비교 → 파라미터 승인 → 실제 분기 운영**으로 정했다.
- **구성:** 현재 위치(완료와 미검증 구분), 사용자가 정할 것 4가지(D1 현금, D2 현금을 5번째 자산으로 둘지, D3 원화/달러 낙폭 기준, D4 5%p 즉시 채택 여부), 판단 흐름도와 해석표, Phase 0~5 로드맵, 과거 데이터 비교 설계, 위험과 대응, 바로 할 일.
- **새로 짚은 점:** 해외2에는 현금이 약 18% 있는데, PRD는 "네 ETF 100%"만 연구 범위로 잡고 있었다. 1차 대화에서 현금 처리 방식을 물었지만 답이 없었기 때문에, 이를 0단계 과제로 올렸다.

## 4. AI — 현금 정책 반영

- Pine은 '별도로 남겨둘 현금' 기본값이 이미 0이라 계산식을 바꿀 필요가 없었다. 결정 사항은 계획안, PRD §10, Pine 설명서 §3.3, 계정 확인 기록에 반영했다.
- **영향 (2026-10-26 관측값 기준 계산 예시):** 현금을 포함하면 네 ETF 모두 목표보다 부족하다. 가장 많이 벗어난 종목은 SCHD로 약 −5.88%p다. 2027년 1월 초 분기 점검 때도 비슷하면 `REBALANCE_REVIEW`가 뜨고, 검토 내용은 **매도 없이 현금으로 부족분을 채우는 것**이다.
- PRD의 "네 ETF 100%" 전제와 실제 계정 운영 방식이 이로써 일치하게 되었다.

## 8. AI — 후보 15개 재검토와 재선정안

TradingView 원문 페이지를 직접 열어 Boost(좋아요) 수를 확인했다. 결과는 [재선정 보고서](tradingview_algorithm_reselection_2026-10-27.md)로 남겼다.

**이전 검토에서 부족했던 점**
- 인기 상위 스크립트가 비교표에 없었다. Smart Money Concepts(176.6K), Squeeze Momentum(117.6K), SuperTrend 지표판(84.3K), Williams Vix Fix(66K), WaveTrend(61.3K)가 빠져 있었다.
- SuperTrend는 원조 지표판(84.3K) 대신 가상매매용 STRATEGY판(25.1K)을 인용했다. 그래서 Chandelier(29.7K)가 더 인기 있는 것처럼 보였다.
- 같은 계열(ATR 추적선) 지표 두 개를 서로의 "확인"으로 쓰고 있었다.
- 포트폴리오 도구 두 개는 Boost가 772와 77에 그쳤다.

**평가 기준:** 목적 적합성, 주봉에서 쓸 수 있는지, 과거 신호가 나중에 바뀌지 않는지(리페인트), 설명 가능성, 역할 중복, 재현성, 인기(1차 필터일 뿐 성과 증거는 아님).

**결론**

| 역할 | 이전 | 재선정 |
|---|---|---|
| 추세 지표 | Chandelier + SuperTrend STRATEGY판 | **SuperTrend 원조 지표판(84.3K) 하나** |
| 공포 지표 | 없음 | **CM_Williams_Vix_Fix(66K) 신규** |
| 과거 데이터 비교군 | — | Chandelier, 40주 이동평균(Faber 2007, 학술 근거) |

- SuperTrend는 "추세가 꺾였나"에 답한다. 같은 계열에서 인기가 가장 높고, Pine 내장 함수와 계산이 같아 재현하기 쉽다.
- Vix Fix는 "지금 공포성 급락인가"에 답한다. 추세 지표가 가장 늦게 반응하는 바닥 근처에서, 부족한 종목을 채울지 판단하는 데 다른 정보를 준다.
- **제외 이유:** SMC와 Squeeze는 단기 진입용이다. UT Bot, Pivot Point SuperTrend, AlphaTrend는 같은 계열이거나 설명이 어렵다. Lorentzian은 4~12시간 차트용 블랙박스다. Nadaraya-Watson은 기본 설정에서 리페인트된다. WaveTrend, Hull, QQE MOD는 단기 지표라 분기 운용에 맞지 않는다.
- 계획안에 재선정 안내와 과거 데이터 비교 항목(S5 추세 지표 교체, S6 Vix Fix 효과)을 추가했다. Pine 수정은 승인 후 진행하기로 했다.

## 10. AI — Pine v0.3 구현

**Vix Fix 공식 확인:** 원문 소스는 로그인해야 볼 수 있어 직접 대조하지 못했다. 공식과 기본값(22/20/2/50/0.85)은 LuxAlgo 해설로 교차 확인했다(검증 필요로 표시).

**Pine 변경 (`pine/quarterly_etf_review.pine`)**
- Chandelier 계산과 표시를 제거하고 SuperTrend(주봉 10·3)를 주 지표로 바꿨다. 조기 점검 후보도 SuperTrend 전환 기준으로 판정한다.
- 표에 Vix Fix 열을 추가했다(공포 구간/평상과 수치).
- 해석 규칙: 부족 + 하락 + 공포 구간이면 "하락+공포: 1차 분할 보충 검토"로 표시한다. 매도 쪽 판단과 목표비중에는 영향이 없다.
- 별도 현금에 0이 아닌 값이 들어가면 주황색 경고를 띄운다. 알림에 현금 정책과 허용폭을 표기한다.

**참조 규격과 테스트**
- `tools/policy_reference.py`에 `vix_fix()`, `interpret()`를 추가했다.
- 테스트는 17개에서 22개로 늘었고 모두 통과했다.
- 실패 1건은 테스트 설계 문제였다. 기준치 바로 아래 값이 다른 판정 조건(볼린저 상단)에 걸렸고, 두 조건을 따로 시험하도록 고쳤다.
- **발견한 성질:** Vix Fix는 "최근 50기간과의 상대 비교"라서, 아주 조용한 시기에는 작은 하락도 공포 구간으로 판정될 수 있다. 설명서에 약점으로 적고 과거 데이터 검증 항목으로 올렸다.

**문서 갱신:** 설명서(SuperTrend·Vix Fix 쉬운 설명, 새 해석표), README, PRD, 재선정 보고서, 계획안.

**미검증:** TradingView 컴파일·실차트, 원본 지표와의 신호 일치, 알림 수신, 과거 데이터 성과.

## 12. AI — 설치·화면 구성 안내

- **핵심:** 차트 네 개를 띄울 필요는 없다. SCHD 차트 하나에 스크립트를 붙이면 나머지 세 종목을 불러와 오른쪽 위 표에 한꺼번에 보여 준다.
- **순서:** 슈퍼차트 열기 → `AMEX:SCHD` 선택 → 1시간(60분) → 일반 캔들 → 정규 거래시간 → Pine Editor에 붙여넣기·저장·차트에 추가 → 입력값(수량, 현금, 별도 현금 0, 확인 시각, 변동 반영 체크) → 표 확인.
- **SCHD 1시간 차트인 이유:** 스크립트가 이 조건을 직접 검사해, 다르면 `DATA_CHECK`를 띄운다. 판단은 전일 종가와 확정 주봉으로 하고, 1시간 단위는 분기 첫날 알림을 빨리 받기 위한 설정이다.
- **다중 차트 (2026-10-27 가격표 기준):** 한 화면당 차트 수는 무료 1, Essential 2, Plus 4, Premium 8, Ultimate 16개다. 이 스크립트는 지표 1개라 무료 요금제(차트당 지표 2개)로도 쓸 수 있다. 4분할 화면을 쓸 경우 우리 스크립트는 SCHD 1시간 칸에만 붙이고, 나머지 칸은 주봉 + 기본 Supertrend로 눈으로만 참고한다. 무료에서는 "+"(심볼 비교) 버튼으로 다른 종목을 겹쳐 볼 수 있다.
- **처음 붙였을 때:** 컴파일 오류가 나면 콘솔 메시지를 공유하고, `DATA_CHECK`면 노란 줄의 원인을 확인한다.
